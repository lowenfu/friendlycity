
# 友善營業場所

參考網址: https://www.friendlycity.url.tw/

## 🚀 快速開始

### 安裝與執行

1. **安裝依賴套件**
```bash
npm install
```

2. **設定環境變數**
```bash
cp .env.example .env
```

3. **啟動 API 伺服器**
```bash
npm start
```
或開發模式（自動重啟）：
```bash
npm run dev
```

4. **開啟前台頁面**
- 前台：開啟 `index.html`
- 後台：開啟 `admin.html`

## 📝 系統架構

### 技術特點
- ✅ **HTTPS 支援**：所有 API 請求使用 HTTPS 協定
- ✅ **CDN 圖片處理**：圖片使用 CDN 加速載入
- ✅ **分頁顯示**：前台每頁 9 筆，後台每頁 10 筆
- ✅ **智慧排序**：依最後修改時間排序（最新在前）
- ✅ **CRUD 後台**：完整的新增、編輯、刪除功能
- ✅ **搜尋篩選**：支援名稱、地區、年度多維度篩選

### API 端點

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/places` | 取得所有場所（支援查詢參數） |
| GET | `/api/places/:id` | 取得單一場所 |
| POST | `/api/places` | 新增場所 |
| PUT | `/api/places/:id` | 更新場所 |
| DELETE | `/api/places/:id` | 刪除場所 |
| GET | `/api/statistics` | 取得統計資料 |
| GET | `/api/health` | 健康檢查 |

### 查詢參數範例
```
GET /api/places?category=餐飲&area=左營區&year=113&search=咖啡
```

## 網站架構
### 🎯 前台功能（index.html）

#### 1. 場所分類
- **大圖示分類**：餐飲、診所、藥局、一般商店
- 點選後顯示該分類下的友善營業場所
- **分頁顯示**：3×3 網格，每頁 9 筆資料
- 依最後修改時間排序（最新在前）

#### 2. 多維度篩選
- **地區篩選**：Checkbox 多選（例如：苓雅區、前鎮區）
- **場所名稱搜尋**：模糊比對（例如輸入"大"可找到"義大利餐廳"）
- **年度篩選**：下拉選單選擇年度
- 篩選條件可組合使用

#### 3. 顯示資訊
- 場所圖片（使用 CDN 加速）
- 年度、場所名稱、地址、類型、區域
- 電話、友善特色詳細說明

### 🔧 後台功能（admin.html）

#### 1. 資料管理
- ✏️ **新增**：新增友善營業場所記錄
- 📝 **編輯**：修改現有場所資訊
- 🗑️ **刪除**：移除場所記錄（需確認）

#### 2. 搜尋與排序
- 搜尋：場所名稱、地址、區域
- 排序：可按任意欄位排序
- 分頁：每頁顯示 10 筆資料

#### 3. 自動更新
- 新增/編輯時自動更新「最後修改時間」
- 資料自動依時間排序

## 📦 資料結構

```json
{
  "id": 1,
  "名稱": "泮咖啡",
  "分類": "餐飲",
  "地址": "高雄市左營區蓮潭路176號",
  "區域": "左營區",
  "年度": "113",
  "電話": "07 585 6868",
  "網址連結": "https://example.com/pan-coffee",
  "友善特色": "1.無障礙入口\n2.無障礙廁所",
  "圖片": "https://cdn.example.com/images/pan-coffee.jpg",
  "最後修改時間": "2025-12-29T10:30:00"
}
```

### 欄位說明
- `id`：唯一識別碼（自動產生）
- `名稱`：場所名稱 *（必填）
- `分類`：餐飲/診所/藥局/一般商店 *（必填）
- `地址`：完整地址 *（必填）
- `區域`：行政區域 *（必填）
- `年度`：認證年度
- `電話`：聯絡電話
- `網址連結`：官方網站或社群連結（必須使用 HTTPS）
- `友善特色`：無障礙設施說明
- `圖片`：場所照片網址（建議使用 CDN）
- `最後修改時間`：自動記錄（ISO 8601 格式）

## ♿ 友善特色書寫規範

### 標準範本格式

#### 1. 出入口
- **坡度等級**：平坦、低門檻、高門檻、緩斜坡、陡斜坡
- **門型**：無門、自動門、好推拉門、難推拉門
- **坡度計算**：`tan⁻¹(垂直高度/水平長度)`
  - 快速算法：高度 × 9 的長度，坡度約 12°
  - 範例：高度 5cm → 長度 50cm（坡度 10°，好推）
  - 範例：高度 5cm → 長度 40cm（坡度 >12°，難推）

#### 2. 廁所
- 地面：平坦、低門檻、高門檻
- 門：好推拉門、難推拉門
- 空間：是否足夠輪椅迴轉（需 120cm）
- 設施：是否有扶手

#### 3. 通道
- 主要通道是否足夠輪椅通行（需 90cm）

#### 4. 用餐區
- 桌下是否有足夠容膝空間（高 70cm、深 30cm）

#### 5. 其他友善設施
- 友善充電座
- 歡迎導盲犬
- 友善優先席
- 兒童座椅

### 填寫範例
```
1.出入口：平坦地面，自動門，輪椅使用者可獨立進入
2.廁所：無障礙廁所，空間足夠輪椅迴轉（120cm），設有扶手
3.通道：主要通道寬度 120cm，輪椅可雙向通行
4.用餐區：桌下高度 75cm，深度 40cm，輪椅使用者可舒適用餐
5.其他：歡迎導盲犬、提供友善充電座、設有兒童座椅
```

## 🔒 安全性建議

1. **使用 HTTPS**：所有 API 請求和外部連結都應使用 HTTPS
2. **環境變數**：敏感資訊（API 金鑰、密碼）存放在 `.env` 檔案
3. **CORS 設定**：限制允許的來源網域
4. **輸入驗證**：後端 API 應驗證所有輸入資料
5. **圖片 CDN**：使用 CDN 服務加速圖片載入

## 🚀 部署建議

### 前端部署
- **GitHub Pages**：免費靜態網站託管
- **Netlify / Vercel**：支援 HTTPS 的現代部署平台
- **Cloudflare Pages**：全球 CDN 加速

### 後端部署
- **Heroku**：簡單易用的 PaaS 平台
- **Railway**：現代化部署平台
- **AWS / GCP / Azure**：企業級雲端服務

### 資料庫建議
目前使用記憶體儲存，建議升級為：
- **MongoDB Atlas**：雲端 NoSQL 資料庫（免費方案）
- **PostgreSQL**：關聯式資料庫
- **Firebase Realtime Database**：即時同步資料庫

## 📖 使用說明

### 前台使用
1. 開啟 `index.html`
2. 點選分類圖示（餐飲、診所、藥局、商店）
3. 使用篩選器精確搜尋
4. 瀏覽分頁查看所有場所

### 後台管理
1. 開啟 `admin.html`
2. 點選「新增場所」建立記錄
3. 使用「編輯」按鈕修改資料
4. 使用「刪除」按鈕移除記錄
5. 搜尋欄可快速找到特定場所
